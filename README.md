# ADR Engine: Reworked

**ADR Engine: Reworked** is now open-source and officially released!

You're free to use this engine, modify its source code, and add new features to your own engine or projects.

## Credits

If you decide to use or implement features from ADR Engine: Reworked into your own engine, please consider giving credit.

**Credit is not mandatory, but it is greatly appreciated!**

I appreciate anyone who takes the time to use, modify, or contribute to this project.

## A Farewell to the Original ADR Engine

Rest in peace to the original ADR Engine.

Unfortunately, the original source code was deleted, and this project is a complete rework rather than a continuation of the original source.

This reworked version introduces new features, changes, and improvements.

| Version | Engine Base |
|---|---|
| Original ADR Engine | Psych Engine 1.0.4 |
| ADR Engine: Reworked | Psych Engine 0.7.3 |

Although the original ADR Engine was based on Psych Engine 1.0.4, this reworked version uses Psych Engine 0.7.3 as its foundation.

## ADR Engine History

Here is the complete list of names and versions throughout the project's development:

1. **ANJ Engine** — Originally based on HRK Engine.
2. **ANJR Engine**
3. **ANJRE**
4. **ANJR Hub Engine**
5. **ADR Engine** — Based on Psych Engine 1.0.4.
6. **ADR Engine: Reworked** — Current project.
7. **ADR Engine: Redux** — Future planned project.
8. **ADR Engine: Reboot** — Another future planned project.
9. **ADR Engine: Overhauled** — Planned final entry in the ADR Engine series.
